Конфигурация sms, email, telegram только для примера и не является рабочей, поэтому результатом работы без подключения рабочих сервисов будет попытка отправить сообщение по каждому каналу, неудача и повторы попыток.  
  
Формат успешного ответа предполагает id уведомления и статус "взято в работу" (queued).
  
Проверить можно через через браузер: 127.0.0.1:8080/api/send/ или curl: curl -X POST http://localhost:8000/api/send/ -H "Content-Type: application/json" -d '{"user_id":"you@mail.com","title":"Тест","message":"Работает!"}'
